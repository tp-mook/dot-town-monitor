# ドット町モニター

ホームページを「町」、ページを「家」、訪れた人を「小人」にして、アクセス状況をドット絵で見える化する監視アプリです。

- 来た人は帽子の色で来訪元（検索・直接・AIチャット・SNS）がわかる
- クローラー・フォーム営業ロボット・攻撃の疑いのある相手を見分けて表示する
- 小人や家をクリックすると、道のり・滞在時間などの数値が見られる

## いまの状態
